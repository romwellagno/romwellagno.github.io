01 / Project Overview

A desktop 2D shifting-world puzzle-adventure where solving mathematics and physics questions physically changes the game world.

PARADOX puts the player on a network of separated islands. Each level hides three mathematical terminals; approaching one opens a four-choice question. A correct answer activates a deterministic bridge group or gate, animates the change, and rebuilds the adjacency-list graph so newly reachable routes match the visible world. Wrong submitted answers cost one of five shared campaign lives. Reaching the exit requires actual movement — answering alone never completes a level.

This is Version 2 of the original game program, rebuilt with dynamic graph connectivity so every correct terminal answer reconstructs the traversal graph in real time.

02 / Key Features

The Shifting World

Terminal answers toggle bridges, gates, and machinery with animated state changes and live graph reconstruction.

10 Progressive Levels

Easy (1-3), Medium (4-6), Hard (7-8), Nightmare (9-10).

30-Question Fixed Bank

Algebra, functions, quadratics, trigonometry, geometry, and physics (force, work, energy, power) with hints and worked explanations.

BFS Pathfinding

Displays the shortest current walking route when the exit is reachable.

DFS Exploration

Highlights the connected region around the traveler.

Campaign System

Five shared lives, scoring (100 per answer, 50 per level, +50 perfect clear), sequential unlocking, local saved progress and best records.
