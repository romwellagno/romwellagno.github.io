Project 02 2025

HYDROFLO

HYDROFLO, or Hydrologic Drainage Automation and Flood-Level Optimizer, is a Computer Engineering academic proposal for an integrated flood control concept intended for barangays near coastal areas and rivers. The project explores how drainage automation, temporary rainwater storage, water-level monitoring, and controlled pumping can support safer and more resilient community infrastructure.

Full Name Hydrologic Drainage Automation and Flood-Level Optimizer
Type Computer Engineering Proposal
Focus Flood control and drainage automation
Core Concept Underground tank, sensors, flood gate, and pumping system
Model Miniature demonstration prototype concept
Status Completed academic proposal
