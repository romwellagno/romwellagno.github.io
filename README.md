## Featured Projects

### HYDROFLO

**Hydrologic Drainage Automation and Flood-Level Optimizer**

A Computer Engineering academic proposal focused on flood-control support, drainage automation, temporary rainwater storage, water-level monitoring, and controlled pumping for flood-prone communities.

### E-Barangay Appointment and Queue Management System

A Java Swing desktop application proposal developed using **Java**, **Java Swing**, and **Eclipse IDE**. The system focuses on appointment scheduling, queue organization, administrative service flow, and public-service technology learning.

### ZORA AI Assistant

A personal AI assistant project developed using **Python**, **Visual Studio**, **Llama**, and **Homebrew**. ZORA can now speak fluently, access the internet, and respond to voice-based questions.

### Second Brain AI System

A personal learning and knowledge workflow built using **Llama**, **Copilot**, and **Obsidian** as storage. It helps organize lecture-based information, generate new ideas from class materials, and support better understanding of academic subjects.
