System Details

E-Barangay Appointment and Queue Management System.

A desktop-based Java Swing application concept that integrates appointment scheduling, queue validation, queue administration, and a real-time Now Serving display for barangay service operations.

Desktop GUI Application Java Java Swing Queue Management
01 / Overview

A staged system for appointment booking, queue validation, and service processing.

The E-Barangay Appointment and Queue Management System is designed to simulate a more organized barangay service workflow. Instead of treating appointment scheduling and queue processing as one continuous action, the system separates them into clearer stages: appointment creation, queue check-in, queue validation, administrative control, and Now Serving updates.

This structure reflects a more realistic service environment because users must confirm their presence before being included in the active queue. Barangay employees can then manage the validated queue through an administration interface.

02 / Technical Summary
System Type Desktop GUI Application
Language Java
GUI Framework Java Swing
Data Structure ArrayList for storing queue data
Queue Format Q0001 for Regular users, SP0001 for Senior/PWD users
Main Output Queue number, assigned window, waiting time, and Now Serving updates
03 / Core Modules

Appointment Module

Allows users to enter their name, choose a barangay service, select a date and time, and identify their user type before receiving a generated queue number.

Queue Module

Handles check-in and validation. Users must confirm their queue number before they are added to the active queue for service processing.

Queue Administration

Gives barangay staff control over queue movement, service windows, and the process of calling the next validated client.

Now Serving Display

Shows the current queue number being served for each service window and updates when the queue advances.

User Classification

Supports Regular, Senior Citizen, and PWD users, allowing the system to apply queue formats and conditional prioritization.

Accessibility Design

Uses readable layouts, clear labels, and accessible interface elements to support users such as senior citizens and persons with disabilities.

04 / System Flow
Step 01 User

Book Appointment

The user enters personal details, selects the desired service, chooses a date and time, and identifies their user type.

Step 02 System

Generate Queue Number

The system generates a queue number using the correct format: Q0001 for Regular users and SP0001 for Senior/PWD users.

Step 03 Validation

Check In and Validate Queue Entry

The user proceeds to the Queue Module, enters their name and queue number, and must be validated before being added to the active queue.

Step 04 Admin

Process Queue

Barangay employees use the Queue Administration Module to call the next client, manage service windows, and update queue progress.

Step 05 Display

Update Now Serving

The Now Serving Display updates automatically to show the current queue number being served for each service window.

05 / Program Design
main() Initializes the application
bookAppointment() Handles appointment input and queue generation
checkInQueue() Validates queue entries before active processing
generateQueueNumber() Assigns Q or SP queue number format
assignWindow() Determines the service window for the user
updateNowServing() Updates the current number displayed per service window
