05 / Project Idea Lab

E-Barangay System Concept

My recent project proposal focuses on a barangay service system with four interconnected modules: Appointment, Queue, Queue Administration, and Now Serving Display. The goal is to create a more organized, accessible, and transparent service flow.

  • Appointment booking with name, service, date, time, and user type
  • Queue number generation for Regular, Senior, and PWD users
  • Queue check-in validation before entering the active queue
  • Queue administration interface for barangay employees
  • Now Serving display for real-time queue updates
  • Accessibility-focused interface for senior citizens and PWD users
