01 / Currently Building

Developing my technical foundation through programming, systems, AI, and documentation.

I am currently developing my skills in Computer Engineering through programming fundamentals, Java development, Python experimentation, interface design, object-oriented thinking, system planning, engineering proposal writing, AI assistant development, and technical documentation.

My programming foundation started with C++, where I learned basic syntax, variables, conditionals, loops, functions, and problem-solving logic before expanding into Java, Python, HTML, and CSS.

I also use Eclipse IDE for Java programming, Java Swing interface development, academic desktop application work, and organizing project files during system development.

One of my current major personal projects is ZORA, my own AI assistant concept. I am developing it in Visual Studio using Python, with Llama-based AI experimentation and a local development setup supported by Homebrew.

ZORA can now access the internet, respond to voice questions, and speak fluently. The project is still under active development, and public details are kept limited to protect the system direction and implementation approach.

I also created a Second Brain using Llama, Copilot, and Obsidian as storage. It helps me organize lecture-based knowledge, generate new ideas from my class materials, and understand my subjects more effectively.
