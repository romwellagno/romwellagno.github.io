01 / Project Overview

A student management system for grades, attendance, and reports.

School Grading System and Records Version 01 is an academic desktop application developed in Java with IntelliJ IDEA. It organizes student information, subject grades, attendance totals, academic standing, and final report summaries in one structured interface.

The project focuses on practical record management. It allows student data and subject performance to be entered, reviewed, and summarized through tables, reports, computed averages, attendance percentages, and pass or incomplete status indicators.

This page presents the public portfolio overview and interface screenshots only. Source code and internal implementation details are kept private to protect originality and academic integrity.

03 / Development Focus

Grade Computation

The system computes subject averages, general weighted average, college equivalent, and student status based on encoded grade records.

Attendance Tracking

Attendance is organized by term, allowing prelim, midterm, finals, subject attendance, and overall attendance percentages to be shown clearly.

Record Management

Registered student records can be viewed in a table, inspected in a detailed report window, edited, and removed as part of the system workflow.

Java and IntelliJ IDEA

The project was developed with Java in IntelliJ IDEA, applying object-oriented programming to an academic records workflow.
